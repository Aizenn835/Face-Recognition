Step by step of installing in school before testing:

Python 3.12 or 3.11 need here: to check do python --version

1. git clone https://github.com/Aizenn835/Face-Recognition.git
2. cd Face-Recognition
3. python -m venv .venv
4. .venv\Scripts\activate
5. pip install dlib-bin
6. pip install face_recognition --no-deps
7. pip install face_recognition_models Click numpy Pillow opencv-python deepface tf-keras "setuptools<81"
